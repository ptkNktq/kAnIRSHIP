# kAnIRSHIP

飛行船アドベンチャー - ブラウザベースのテキストアドベンチャーゲーム

## 概要

飛行船を操り、様々なロケーションを巡るブラウザゲームです。フレームワークを使わず、純粋なHTML/CSS/JavaScriptで構築されています。

## ゲームシステム

- **ステータス管理**: 耐久値・燃料・所持金（バルク）
- **天候システム**: 晴れ / 曇り / 雨 / 嵐 / 雪（SVGアイコン付き）
- **時間システム**: ゲーム内の日数・時刻管理
- **インベントリ**: カバン＋船体コンテナのグリッド管理
- **ロケーション**: 小さな町、大きな町、島、造船所、お店、飛行船（船上）

## ファイル構成

```
├── index.html          # 初期版ゲーム画面
├── game.html           # メインゲーム画面
├── game.js             # ゲームのコアロジック
├── style.css           # スタイルシート
├── location/           # ロケーションモジュール（町・島・造船所・店など）
├── features/           # 機能モジュール（インベントリ・天候管理）
├── resources/          # SVGアセット・DOM読み込み
└── tests/              # テストファイル
```

## 技術的特徴

- ES Modules によるモジュール分割
- SVGによるドット絵風の飛行船・天気アイコン・アイテム描画
- モーダルUIでインベントリ・情報表示
